\chapter{Arquitectura del software}
\vspace{3\baselineskip}

En este capítulo se presentan los patrones de diseño de arquitectura de software considerados para estructurar el software de este trabajo. Teniendo como premisa el diseño modular orientado a garantizar la escalabilidad, mantenibilidad y el desacople estructural entre componentes del sistema. Para ello, se analizan las variantes Modelo-Vista-Controlador (MVC), Modelo-Vista-Presentador (MVP) y Modelo-Vista-VistaModelo (MVVM), analizando el modo en que cada uno gestiona la separación entre la lógica de presentación, la lógica de negocio y el manejo de datos. 

\section{Patrones de arquitectura del software}

Actualmente, para el desarrollo de software en general, se existen diversos patrones de diseño que ayudan a organizar el código, mejorar la mantenibilidad y facilitar la escalabilidad. Algunos de esos patrones son:

\begin{itemize}
    \item \textbf{Modelo-Vista-Controlador (MVC)}: Es un patrón de diseño de software que se utiliza para separar la lógica de presentación, la lógica de negocio (procesar los datos, realizar cálculos y tomar decisiones), y la gestión de eventos en una aplicación. En este patrón, el \textbf{Modelo} representa los datos y la lógica de negocio, la \textbf{Vista} se encarga de la presentación visual y la interacción con el usuario, y el \textbf{Controlador} actúa como intermediario entre el Modelo y la Vista, gestionando las entradas del usuario y actualizando la Vista en consecuencia.
    \item \textbf{Modelo-Vista-Presentador (MVP)}: Es similar al MVC, pero con una separación más clara entre la lógica de presentación y la lógica de negocio. En este patrón, el \textbf{Presentador} se encarga de manejar la lógica de presentación y la interacción con el usuario, mientras que el \textbf{Modelo} sigue representando los datos y la lógica de negocio. La \textbf{Vista} se limita a mostrar los datos proporcionados por el Presentador y a enviar las acciones del usuario al Presentador.
    \item \textbf{Modelo-Vista-VistaModelo (MVVM)}: Es una evolución del MVP, el cual introduce el concepto de \textbf{VistaModelo}, que actúa como un enlace entre el Modelo y la Vista. En este patrón, la VistaModelo expone los datos y comandos que la Vista puede enlazar directamente, lo que facilita la separación de responsabilidades y mejora la testabilidad de la aplicación.
\end{itemize}
