\section{Análisis de precisión}
\label{sec:analisis_precision}

En este apartado se analizó la diferencia de precisión que se puede tener con el método usado actualmente el Laboratorio de Alta Tensión, contra el software desarrollado en el presente trabajo. Para ello, se compararon los resultados obtenidos al analizar el mismo conjunto de impulsos generados con el TDG \cite{iec61083_2}, en tres variantes:
\begin{enumerate}
    \item \textbf{Manual}: Se graficó cada impulso, y se lo analizó aplicando el método descripto en el Anexo C de la norma IEC 60060-1 \cite{iec60060_1}. Para este caso, se usó la versión de las ondas de 8 bit, ya que se corresponde con la resolución que se usa actualmente en el laboratorio.
    \item \textbf{8 bit}: Se generó con el TDG los impulsos de referencia con una resolución de \num{8} bit, acorde a la resolución del osciloscopio \cite{gds1000au_UserManual} empleado en este trabajo.
    \item \textbf{16 bit}: Se generó con el TDG los impulsos de referencia con una resolución de \num{16} bit que es la máxima disponible, para evaluar cómo se comporta el software en caso de que use un osciloscopio con mayor resolución.
\end{enumerate}

El TDG tiene un total de \num{29} casos de impulsos plenos (LI), y \num{5} de impulsos cortados (LIC), de los cuales se seleccionaron \num{5} LI y \num{2} LIC, que son los más representativos de lo que se observa habitualmente en el laboratorio.
