\section*{Resumen}
\label{sec:resumen}
\addcontentsline{toc}{chapter}{Resumen}
El presente Trabajo Final aborda el diseño, la implementación y la validación metrológica de un sistema de software integral para la automatización de la captura y análisis de ensayos de impulso atmosférico (\qty[parse-numbers=false]{1.2/50}{\micro\second}), conforme a las normas IEC 60060-1~\cite{iec60060_1} y 61083-2~\cite{iec61083_2}. El trabajo responde a la necesidad de optimizar los procedimientos manuales de medición en el Laboratorio de Alta Tensión (FCEFYN-UNC), reduciendo los tiempos operacionales y eliminando el error operacional humano.

El sistema integra una capa de abstracción de hardware basada en el protocolo VISA y comandos SCPI para controlar un osciloscopio digital GW Instek GDS-1102A-U \cite{gds1000au_ProgrammingManual}. Desarrollado en Python bajo el patrón arquitectónico MVP, garantiza el desacoplamiento entre la interfaz gráfica y la lógica funcional con sondeo asíncrono no bloqueante.

El motor de cálculo numérico ejecuta el algoritmo indicado en la IEC 60060-1. Aplicando regresión no lineal con el algoritmo de Levenberg-Marquardt con una función de doble exponencial, en conjunto con un filtro digital de fase cero para eliminar el ruido indeseado, logrando sintetizar la curva de tensión de ensayo~\cite{iec60060_1}. Por su parte, la información se administra jerárquicamente en formato HDF5, con respaldos en texto plano (CSV) y exportación a planillas de cálculo.

La calibración del software se realizó inyectando los registros patrón del generador de datos de prueba de la 61083-2~\cite{iec61083_2}, verificando que los errores en el cálculo de los parámetros característicos ($U_t$, $T_1$, $T_2$, $T_c$ y $OS\%$) cumplan las tolerancias admisibles.

\section*{Abstract}

This Final Project addresses the design, implementation, and metrological validation of a comprehensive software system for the automation of the acquisition and analysis of lightning impulse tests (\qty[parse-numbers=false]{1.2/50}{\micro\second}), in accordance with IEC 60060-1~\cite{iec60060_1} and IEC 61083-2~\cite{iec61083_2} standards. The work responds to the need to optimize manual measurement procedures at the High Voltage Laboratory (FCEFyN-UNC), reducing operational times and eliminating human operational error.

The system integrates a hardware abstraction layer based on the VISA protocol and SCPI commands to control a GW Instek GDS-1102A-U digital oscilloscope \cite{gds1000au_ProgrammingManual}. Developed in Python under the MVP architectural pattern, it guarantees decoupling between the graphical user interface and the functional logic through non-blocking asynchronous polling.

The numerical calculation engine executes the algorithm specified in IEC 60060-1. By applying nonlinear regression using the Levenberg-Marquardt algorithm with a double exponential function, together with a zero-phase digital filter to eliminate unwanted noise, it successfully synthesizes the test voltage curve~\cite{iec60060_1}. Furthermore, information is managed hierarchically in HDF5 format, with plain text (CSV) backups and spreadsheet export capabilities.

Software calibration was performed by injecting the reference records from the test data generator of IEC 61083-2~\cite{iec61083_2}, verifying that the calculation errors for the characteristic parameters ($U_t$, $T_1$, $T_2$, $T_c$, and $OS\%$) comply with the allowable tolerances.
